# midas_small.tflite

This directory expects the quantized MiDaS small depth model generated by the
conversion script in `tools/` (run once on a dev machine, not on the phone):

```bash
python tools/convert_midas.py --method ai-edge-torch --output app/src/main/assets/midas_small.tflite
```

Requirements and both conversion paths are documented in
`tools/convert_midas.py`. Until the model file exists here, `DepthEstimator`
will fail to initialize at runtime (Milestone 2 in the README covers loading it
in isolation before wiring the live camera).

## yolov8n_fp16.tflite (Mode B / Narrated)

The Mode B object detection model, exported by `tools/convert_yolo.py`:

```bash
python tools/convert_yolo.py --imgsz 320 --output app/src/main/assets/yolov8n_fp16.tflite
```

fp16 quantized with NMS baked into the graph. Unlike the depth model, this one
is loaded lazily — `ObjectDetector` (and therefore Mode B) only initializes
when the user switches to Narrated or Hybrid mode, so a missing model doesn't
break the soundscape.
